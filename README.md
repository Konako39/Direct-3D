# Direct3D 11 基础工程

这是一个面向后续 3D 开发的最小 Windows / Direct3D 11 工程。

当前仅保留：

- Win32 窗口与消息循环
- Direct3D 11 设备、交换链、颜色缓冲和深度缓冲
- 窗口尺寸变化时重建后备缓冲
- 最基础的应用生命周期：初始化、更新、绘制、释放

画面暂时只显示纯色背景。后续可在此基础上加入相机、3D 网格、着色器和场景系统。

## 构建

使用 Visual Studio 打开 `Direct3DProject.sln`，选择 `Debug | x64` 或 `Release | x64` 后构建运行。

按 `Esc` 或关闭窗口即可退出。
